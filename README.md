# Hortifruti · Importação de CSV para Google Sheets

Automação para importar o CSV mais recente de uma pasta do Google Drive, limpar os dados e alimentar a aba `Dados Limpos` no Google Sheets.

## Visão rápida

1. Você coloca um `.csv` na pasta do Drive configurada.
2. Executa a função `importarCSVLimpoDaPasta` no Apps Script.
3. O script mantém apenas colunas essenciais, normaliza dados e adiciona somente linhas novas.
